# DBMS Unit 5 — Transactions, Concurrency Control, Recovery & Security

Detailed study notes covering ACID, schedules, conflict/view serializability, recoverability,
lock-based protocols (2PL, strict, rigorous, conservative), deadlocks, database recovery and
database security — with diagrams, worked PYQ answers, practice numericals and MCQs.

**Read online:** https://parv-005.github.io/dbms-unit5-notes/

## Rebuilding

`index.html` is generated from the sources in `src/`:

```sh
cd src && python3 build.py ../index.html
```
